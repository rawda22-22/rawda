# حجوزات الروضة الشريفة 🕌

تطبيق ويب لإدارة حجوزات زيارة الروضة الشريفة (مواعيد الرجال والنساء، الدفعات، الحسابات بعدة عملات، ومزامنة سحابية عبر Firebase).

## النشر
أي `push` على فرع `main` بيشغّل GitHub Actions وينشر الموقع تلقائياً على GitHub Pages.

الرابط بعد النشر:
`https://<اسم-المستخدم>.github.io/<اسم-الريبو>/`

## الإعداد لأول مرة
1. **Settings → Pages → Source** اختار **GitHub Actions**.
2. في **Firebase Console → Authentication → Settings → Authorized domains** أضف:
   `<اسم-المستخدم>.github.io`

## 🧾 بوت أرشيف المدفوعات (اسكرينات التحويل)
الموظف يبعت اسكرين التحويل لبوت تليجرام (نفس البوت اللي في إعدادات الموقع) واكتب في وصف الصورة **كود الحجز** (🔖 جنب اسم العميل) أو تليفون العميل، والمبلغ لو مش المتبقي كله.
البوت بيشتغل من GitHub Actions كل 5 دقايق (`.github/workflows/payments.yml`):
يرفض الاسكرين المكرر، يحفظ الصورة في قناة الأرشيف، يسجّل الدفعة برقم (`P-00001`) ويحدّث المدفوع في الحجز، ويرد على الموظف.

**الإعداد:**
1. انشر قواعد Firestore الجديدة (فيها collection `payments`).
2. اعمل قناة أو جروب خاص للأرشيف، ضيف البوت فيه أدمن، وحط الـ Chat ID بتاعه في الإعدادات ← «قناة أرشيف الاسكرينات».
3. من قائمة الموظفين دوس 🤖 لكل موظف، وخليه يبعت للبوت في الخاص الرسالة اللي هتظهر (`/link 123456`).
4. (اختياري) فعّل «التحويل والمحفظة والبطاقة يتسجلوا باسكرين من البوت بس».
